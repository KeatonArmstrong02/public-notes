Welcome to my first website! 
This is where I learn in public and post notes which don't make it onto my [substack](https://keatonarmstrong.substack.com/).

I decided upon this design to allow for a more exploratory user experience. Rather than a top-down structure, this build with Quartz allows me to publish directly from my Obsidian vault. Allowing for a mirrored experience of peering into my notes as I write them.
