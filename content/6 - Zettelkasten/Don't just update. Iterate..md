# Don't just update. Iterate.

Update means you changed the code
Iteration is improving upon the flaws

You can't find flaws if you don't let the program run. It needs to leave theory and get tested.

You can keep tweaking the code all you want, but eventually you gotta let it fly and see where you go. Iterate along the way, like a plane. You can’t take off with perfect trajectory but you can adjust along the way easily.
