# Make more pots if you want a perfect one

There's a class that got split into two groups. 

Group A is tasked with making a pot as perfectly as possible, but only get one go.
Group B is tasked with making 50 pots. (minimal effort)

In the end, all of the best pots in the class came from the second group.

There is no such thing as great performance ONE time. Get a ton of reps in.
